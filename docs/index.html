⚡ Beyond Stock Ableton Live

Built for What Electronic Producers Actually Need.

Stock Ableton forces producers into expensive 3rd-party plugins for sidechain ducking, phase alignment, and bus clipping. Oxide Studio ships these 5 missing essentials natively with zero-latency DSP.

WORKFLOW SPEED

1. One-Click Bounce-in-Place (Cmd+B)

Stock Ableton's "Freeze & Flatten" is destructive—it wipes MIDI, synths, and automation unless manually cloned, and cannot freeze groups with sidechains. In Oxide Studio, Cmd+B renders offline in-process, preserves the original synth in an underlying inactive take lane, and adds a 1-click Revert to MIDI header.

Ableton Live 12: Destructive Freeze+Flatten / No Group Freeze
Oxide Studio: 1-Click Cmd+B / Non-Destructive Take Lane Revert
SIDECHAIN SHAPER

2. Native DuckShaper (Pump LFO Crossover)

Producers spend $49 on Kickstart 2 or Cableguys ShaperBox to avoid compressor sidechain detector lag. DuckShaper evaluates a 2048-point sample-accurate bezier curve per sample on the audio thread with zero latency, complete with a 4th-order Linkwitz-Riley crossover (120 Hz) to duck ONLY the sub-bass while leaving punch untouched.

Ableton Live 12: Requires $49 3rd-Party VST or Clunky Sidechain Routing
Oxide Studio: Native 2048-pt Bezier Curve + 120Hz Sub Crossover
CLUB MASTERING

3. Club Clipper with 8x Oversampling

Peak-Time Techno, RKT, and Drum & Bass require extreme loudness (-6 to -4 LUFS). Stock Saturator creates harsh aliasing foldback. Club Clipper provides continuously adjustable polynomial knee and 2x, 4x, 8x linear-phase FIR oversampling with shave-meter and instantaneous crest factor readout.

Oversampling: 2x / 4x / 8x Linear FIR
Shave Meter: Peak-to-RMS dB Telemetry
SUB-BASS CORRELATION

4. Kick + Bass PhaseScope

When kick and sub-bass fundamental waveforms oppose each other (30–100 Hz), sound cancels out on club systems. PhaseScope renders dual superimposed circular ring buffers (Kick in neon pink, Bass in laser cyan) with real-time Pearson correlation index (ρ ∈ [-1.0, +1.0]), cancellation warning, and Hilbert phase rotator.

Correlation: Pearson ρ [-1.0 .. +1.0]
Alignment: 0°–360° Hilbert Phase Rotator
LOUDNESS DECK

5. ClubDeck Reference Analyzer

Master telemetry deck with EBU R128 integrated, short-term (3s), and momentary LUFS with selectable target markers (-6 to -8 LUFS for club, -14 LUFS for streaming). Features 4x oversampled true-peak detection, Sub Mono audition switch (<90 Hz), and 1-click Reference Track A/B slot with loudness matching.

Standards: ITU-R BS.1770 / EBU R128
Sub Mono: Side Cancellation Check

⚙️ Modular Rust Architecture

9 Crates, 10 Instruments & 15 Audio Effects.

Organized into clean, decoupled crates with zero circular dependencies. Real-time audio threads maintain zero allocations while GUI and MCP servers interact over lock-free ring buffers.

ableton-core

Lock-free SPSC ring buffers (rtrb), audio buffer slices, sample clock, GlobalScale, and project definitions.

  • Zero audio-thread heap allocations
  • Lock-free atomic communication
ableton-dsp

PolyBLEP oscillators, Cytomic ZDF filters, Mystran 2x-oversampled 4-pole ladder filter, Wavetable, Operator, Drift, and Meld.

  • Padé [4/4] rational saturation
  • Strictly bounded, non-NaN audio
ableton-drums

TR-909 physical drum synthesis models, multi-pad Drum Rack (128-pad bank view), sample slicing, and choke groups.

  • Dual-component kick & tuned snare
  • Quantized transient slicing
ableton-fx

Dynamic multi-device chain hosting EQ Eight, Glue Compressor, Roar saturator, Auto Filter, OTT, Hybrid Reverb, and Limiter.

  • Cytomic SSL bus compressor model
  • 8-band parametric filter cascade
ableton-audio

Native macOS CoreAudio real-time output via CPAL with low-latency device streams and buffer callbacks.

  • Sub-5ms hardware roundtrip latency
  • Real-time thread priority scheduling
ableton-bounce

Offline multi-track WAV renderer, sample-rate conversion, 16/24/32-bit RIFF export, and 4-stem remix extractor.

  • Linkwitz-Riley 4-band crossover
  • Mid/Side harmonic decomposition
ableton-timeline

Session clip launcher, Arrangement multi-track timeline, automation ramps, comping take lanes, and 6-mode warping.

  • OWarper phase vocoder reconstruction
  • Piecewise-linear automation curves
ableton-project

Atomic JSON/RON project persistence and bidirectional Ableton Live 12 Set (.als) Gzip XML parser/serializer.

  • Full round-trip fidelity with Live 12
  • Flate2 Gzip automatic detection
ableton-plugin-scanner

Crash-isolated out-of-process supervisor enumerating and hosting AUv2, VST3, and CLAP plugins.

  • Process isolation crash supervisor
  • Host DAW survives plugin segfaults

Bidirectional .als Interoperability & 1-Click Remix Stems.

Move projects between Ableton Live 12 and Oxide Studio without friction. Extract isolated stems in seconds to remix or sample any track immediately.

LIVE SET INTEROP

Open & Export Ableton Live 12 Sets (.als)

Oxide Studio parses and serializes Gzip-compressed XML (\x1f\x8b) Live Sets directly. Export your Oxide Studio session to project.als to finish in Ableton Live, or open an existing Live 12 set directly in Oxide Studio.

$ oxide-studio --import-als song.als
$ oxide-studio --export-als session.als
✓ Tracks, Tempo, MIDI Clips, and Mixer faders preserved 1:1
